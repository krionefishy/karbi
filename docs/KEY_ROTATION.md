# Ротация ключей шифрования

На этом сервере шифротекстов больше нет: ключи селлеров живут на шлюзе wb-egress и
зашифрованы его Fernet-ключом (`EGRESS_ENCRYPTION_KEY` в `.env` VPS). Токены ботов —
на телеграм-релее, под его собственным ключом.

Ротация ключа шифрования — процедура соответствующего сервиса:

- **wb-egress**: репозиторий karbi-wb-egress; сменить `EGRESS_ENCRYPTION_KEY` можно
  только с перешифровкой строк таблицы `sellers` (аналог прежнего
  `rotate_credentials`, пишется по месту при необходимости — селлеров единицы,
  проще перелить ключи заново через `just seller-set`).
- **релей**: см. репозиторий marketplace-auto-relay.

Историческая процедура ротации `CREDENTIALS_ENCRYPTION_KEYS` удалена вместе с
`wb_core.credentials` (миграция `wc005`) — см. git-историю этого файла.
